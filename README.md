## 执行时间（北京时间）

- 首次：不早于10月28日09:30:05，用首个有效盘口开始估算成交；首个采样建立成交量基线，下一次采样才可能成交。09:40终止、撤销剩余买单。
- 常规调仓：每月首个交易日14:55–14:59:40执行，保持报告“月初收盘调仓”方向；**近收盘有效盘口不能等同官方收盘价**。
- 每日近收盘：前一日收盘涨停、当日不再封板尝试卖出；新ST尝试退出。跌停、停牌、无有效买盘则保留并后续重试。
- 晚间18:20启动公开日线增量更新；月度模型只在新月计划/首次初始化时训练，不每日重训。
- 开盘启动冗余：09:12、09:22、09:32；近收盘启动冗余：14:25、14:40。提前启动的进程等待窗口；全仓库串行，避免重复记账。
- GitHub定时任务可能延迟，不承诺09:30准点。窗口内迟到按实际盘口和时间记账，超过窗口就跳过；绝不倒填开盘/收盘成交。首次因数据未就绪错过则在后续有效开盘窗口尝试，不伪造10月28日成交。

## 数据及模型重建细则

历史源：[BaoStock](https://www.baostock.com/mainContent?file=pythonAPI.md)，日线不复权价 `adjustflag=3`，包含成交状态、历史ST、上市和退市日期；交易日历来自同一源。
逐股票增量gzip缓存，失败单股隔离，活跃主板至少2000只且最近交易日覆盖≥97%才放行；不完整行情禁止交易。
证券主表保留源提供的已退市证券以减轻幸存者偏差，不能保证源完全覆盖所有历史退市证券。

只做600/601/603/605、000/001/002/003；历史当日非ST、正常交易、上市至少120个自然日、20日平均成交额≥2000万元。
**没有额外加3元股价等其他策略过滤条件。**

固定特征：5/10/20/60/120日收益、20/60日波动、20/60日均线偏离、20日高点距离、20日换手率、5日/20日成交额比、20日振幅、下行波动。以源的每日pctChg构造连续收益指数，避免未来前复权因子泄露。

月末特征预测下一完整月的横截面收益；前30%标1、后30%标0，中间剔除。标签结束日必须属于执行月之前的完整月份；当月未结束收益不允许训练。训练只取最后6/12个完整样本月。
XGBoost固定120棵树、深度3、学习率0.05、随机种子42；只用价量，不伪造财报因子。0.75是本模型输出阈值，并非经校准的75%赚钱概率。

## 尽量接近真实成交

- 腾讯公开五档快照，自带行情时间、涨跌停价格、五档价量；每10秒采样，原始解析快照在 reports/quote_audit 留痕。
- 行情超过30秒、跨日、停牌/零成交、ST买入、涨停买入、跌停卖出一律不成交。没有队列数据时不假设能排到涨跌停单。
- 以对手盘五档为基础，额外不利滑点5bp；不突破涨跌停价。每档最多吃可见量10%，每次最多用**委托后新增成交量的1%**。不反复消耗同一时间戳快照。
- 买卖均100股整手，买后T+1卖，先卖后买；现金不可负、旧仓卖不掉不凭空释放资金或持仓名额。为费用留0.5%资金缓冲。
- 佣金双边万3、每笔委托最低5元；卖出印花税万5；过户费双边十万分之一。部分成交按同一委托累计费用增量计算，避免每个片段重复最低5元。
- 报告统一费用假设与本项目逐委托费用不同；真实佣金可在config.json修改。费用参数为模拟假设。
- 企业行动：若持仓出现除权参考价与上日原始收盘不一致，冻结该股撮合并报告reconcile_required，防止将分红送股当盈亏；本版**没有自动分红送股到账**，需核对后调整持仓/现金并解除标志。未知情况不自动编造股数或现金。
- 盘口不是交易所逐笔数据，无法精确重放撤单和队列，估算成交也不等于真实可成交保证。
